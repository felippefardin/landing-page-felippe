# 🚀 Projeto Landing Page com Painel Administrativo

Este projeto é uma landing page desenvolvida como teste prático e base de estudos para aprofundar meus conhecimentos em desenvolvimento web.

## ✨ Funcionalidades principais

- 🔒 Painel administrativo com login seguro (verificação por código via e-mail)
- 📥 Captação de e-mails e contatos via WhatsApp dos clientes e formulários
- 📧 Resposta direta por e-mail com apenas um clique
- 📤 Exportação de dados em Excel, PDF e CSV
- 💳 Integração com APIs de pagamento
- 💬 Integração com API do WhatsApp
- 🗄️ Banco de dados MySQL
- 🔄 Projeto em constante evolução

## 📚 Sobre o projeto

Este projeto conta com múltiplas páginas e é integrado a diversas funcionalidades modernas, simulando situações reais que envolvem landing pages com foco em conversão e administração de dados. Além de servir como estudo, ele também está disponível publicamente para a comunidade.

## 🛠️ Tecnologias utilizadas

- PHP 
- HTML5 / CSS3 / JavaScript
- MySQL
- Bootstrap / Tailwind (dependendo da versão)
- APIs externas (Pagamentos, WhatsApp, etc.)

## 💼 Objetivo

Este repositório também funciona como parte do meu portfólio e pode servir como referência para desenvolvedores que desejam trabalhar com criação de landing pages otimizadas e integradas. Fique à vontade para clonar, sugerir melhorias ou contribuir com ideias.
